# Testler

Python örnekleri ve projeler için testler bu klasörde tutulur.

İhtiyaç oluştuğunda düzen:

- `unit/`: Tek fonksiyon veya küçük modül davranışları.
- `integration/`: Birden çok bileşenin birlikte çalışması.

İlk aşamada test aracı yazmayacağız. Önce test edilen davranışı ve başarısızlık örneğini tanımlayacağız; sonra uygun test aracını ekleyeceğiz.
