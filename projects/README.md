# Projeler

Bu klasörde temel alıştırmalardan daha bütünlüklü uygulamalara ilerleyen projeler bulunur.

Her proje için README şu soruları yanıtlamalıdır:

1. Hangi kullanıcı problemini çözüyor?
2. Girdisi ve çıktısı nedir?
3. Hangi varsayımları ve sınırları vardır?
4. Hangi örneklerle ve testlerle doğrulanır?
5. Neleri özellikle kapsam dışında bırakır?

İlk projeler küçük kalır. Dağıtık sistem, özel framework veya mikro-optimizasyon ancak ölçülmüş bir ihtiyaç olduğunda eklenir.
